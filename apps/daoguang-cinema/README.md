# 奏报之外：文书样片与动态分镜

这是一份前期制作工作拷贝，独立于旧版 `apps/daoguang`。不是最终精修成片。

## 运行与打包

```sh
npm run dev -w @efe/daoguang-cinema -- --port 4176
npm run typecheck
npm run test:core
npm run build -w @efe/daoguang-cinema
node tools/package-daoguang-cinema.mjs
npx playwright test --config playwright.daoguang-cinema.config.ts
```

产物为 `release/daoguang-cinema-workprint.html`，包含全部运行资源，离线播放不请求在线 TTS。三个入口：

- 文书样片：正片时间 74–127 秒，播放 53 秒后自动停下。
- 完整动态分镜：270 秒，23 个镜头段，包含全剧临时旁白。
- 互动动态分镜：127 秒处暂停；A/B 各18秒；可比较后回到同一史实时刻。

## 本次做到了什么

- 折页展开、封套递送、笔影、朱色意象、雨丝与水面细节按时间重建。
- 驿站、御案和江岸采用原创生成绘景。纸页独立合成，海面镜头复用 Three.js 场景。
- 云健临时合成人声，服务返回的句子边界驱动字幕。实际时长与分镜窗口适配，单句加速上限15%，超出直接报错。
- 三音动机、竖琴及大提琴采样、短促纸声与雨滴重新编排。主片与插段使用单一声源切换，暂停/拖动先停止旧声源。
- 独立制作入口、说明和交互控件；观看时控件自动收起。手机保留16:9。

## 必须继续制作的内容

江岸目前是一张绘景加有限水纹、芦苇运动，不是完成的多景层场景。销烟 S03、行军 S13、战后 S16、镇江 S19 仍为气氛占位画面；不能当作相应事件的精确复原。海上部分仍沿用旧版模型与机位。文书只是叙事意象，未使用皇帝手迹或原件。

当前折页和笔仍需材质、接触影与动作精修；生成底图中的远处人物尚未独立活动。临时配音未经过导演最终选声，声音也未做最终响度母带处理。

下一轮先把三张场景底图拆成前中后景，为驿卒、民船及搬运动作独立制作层；补齐销烟与行军画面，再进行整体美术与声音统一。

## 文件关系

`films/daoguang/preproduction/cut.json` 是分镜时序；`src/cut.ts` 将海面镜头映射到旧工程的 FilmProjectStore / Director，保持原模型和水面；`src/art.ts` 负责文书与绘景合成；`src/audio.ts` 负责旁白、音乐、拟音和字幕；`src/main.ts` 负责显式的正片／插段状态。

新增独立入口和素材，工作区锁文件仅登记新入口；旧播放器、旧单 HTML 和原道光网页未改。此版本没有部署替换线上影片。

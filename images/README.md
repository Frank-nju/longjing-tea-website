## 图片规范

- **格式**：优先使用 `.jpg`（照片），图标或插图使用 `.svg`
- **压缩**：建议使用 [Squoosh](https://squoosh.app/) 或 [TinyPNG](https://tinypng.com/) 压缩，单张不超过 300KB
- **色调**：与网站调性一致——偏暖、自然、东方美学，避免过度饱和与商业感滤镜
- **版权**：请使用自拍素材或已获授权的图片，避免侵权

## 临时占位符

在真实图片就位前，相关页面将显示纯色背景或 emoji 占位，不影响布局与功能验证。
